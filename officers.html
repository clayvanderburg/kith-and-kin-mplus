🔑 Officer key kit

Raider.IO can't see the keystone in anyone's bags, so the site learns keys from officers' game clients. This kit installs a tiny addon that listens for guildmates' keys (BigWigs, Details!, Astral Keys and keystone links in chat) and a small uploader window that sends them here whenever WoW saves. The more officers run it, the more keys show up.

⬇️ Download the officer kit (.zip)

Windows only · no admin rights · no Node.js · about 2 minutes.

Install

  1. Unzip it anywhere (your Desktop is fine).
  2. Double-click Install.cmd. If Windows warns that it came from the internet: right-click Install.cmd → Properties → tick Unblock → OK, then run it again.
  3. It finds World of Warcraft by itself and copies the addon in.
  4. Type the officer passphrase (the one the Control Center asks for). It's checked with the site and saved encrypted for your Windows account only.
  5. Say Y to "start automatically" on your gaming PC.

Use

  • Play normally. After logging in, do /reload once so the first batch uploads. Logging out or quitting also uploads.
  • The Kith & Kin Key Uploader window shows what it sent. Minimize it; don't close it.
  • In game, /kkkeys shows how many keys the addon has heard this week.
  • Keys from before the Tuesday reset are ignored automatically.

Update, new passphrase, or remove

  • Update or change passphrase: download the kit again and run Install.cmd.
  • Remove: delete the Kith & Kin Key Uploader shortcuts (Desktop, and Startup via Win+R → shell:startup), the folder %APPDATA%\KithKinKeys, and World of Warcraft\_retail_\Interface\AddOns\KithKinKeys.

Everything in the kit is plain text you can open and read: install.ps1 and KithKinKeysUploader.ps1.
